## Overview

Model-free RL often requires tens of millions of environment steps to solve contact-rich manipulation tasks with sparse feedback. This research template pairs a **Recurrent State-Space Model (RSSM)** with short-horizon **Model Predictive Path Integral (MPPI)** planning in latent space to achieve rapid sample efficiency and smooth torque trajectories.

## Key Capabilities

- **Joint Latent Dynamics & Value Learning**: Learns compact stochastic-deterministic state transitions directly from proprioception and multi-view visual embeddings.
- **Lookahead MPPI Trajectory Optimization**: Evaluates 512 candidate action sequences over a 12-step horizon in latent space, blending terminal value estimates with learned reward predictions.
- **Hybrid Policy Prior**: Warm-starts MPPI sampling distributions with an amortized actor network to reduce planning variance on multi-stage pick-and-insert tasks.

      label: "wm/planner/mppi.py",
      code: `def mppi_step(model, z0, mean, std, horizon=12, samples=512, temp=0.5):
    actions = mean[:, None] + std[:, None] * torch.randn(horizon, samples, mean.shape[-1], device=z0.device)
    returns = model.rollout_value(z0, actions.clamp(-1.0, 1.0))
    weights = torch.softmax(temp * (returns - returns.max()), dim=0)
    next_mean = (weights[:, None] * actions).sum(dim=1)
    return next_mean[0], next_mean`
