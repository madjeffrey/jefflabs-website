## Overview

Modern game-playing agents achieve superhuman tactical depth by coupling a shared policy-value neural network with lookahead search. This project template implements a **distributed self-play MCTS architecture** engineered to maximize GPU inference utilization across asynchronous search threads while continuously validating candidate checkpoints through SPRT/Elo gating.

## Key Engineering Decisions

- **Batched Leaf Inference with Virtual Loss**: Decouples tree traversal workers from GPU forward passes by collecting leaf evaluation requests into dynamic micro-batches (`B = 64`), eliminating host-device synchronization stalls.
- **PUCT Exploration & Dirichlet Root Noise**: Balances tactical exploitation with root exploration during self-play while switching to deterministic visit-count temperature schedules during tournament evaluation.
- **Zero-Copy Replay Ring Buffer**: Streams self-play trajectories directly into pinned memory slabs for asynchronous SGD updates without blocking actor workers.

      code: `inline float puct_score(const Edge& edge, int parent_visits, float c_puct) {
  const float q = edge.visits > 0 ? edge.value_sum / static_cast<float>(edge.visits) : 0.0f;
  const float v_loss = static_cast<float>(edge.virtual_loss);
  const float denom = 1.0f + static_cast<float>(edge.visits) + v_loss;
  const float u = c_puct * edge.prior * std::sqrt(static_cast<float>(parent_visits)) / denom;
  return (q - v_loss * 0.05f) + u;
}`
