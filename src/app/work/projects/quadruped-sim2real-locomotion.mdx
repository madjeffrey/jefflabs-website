## Overview

Deploying learned locomotion policies onto physical quadruped hardware requires handling unmodeled actuator compliance, IMU drift, communication latency, and variable ground friction. This template showcases an **asymmetric actor-critic PPO** pipeline trained across 4,096 parallel GPU physics environments with curriculum terrain generation and zero-shot sim-to-real transfer.

## System Architecture

- **Privileged Critic & Proprioceptive Actor**: During simulation training, the value critic consumes exact contact forces, local terrain height scans, and link friction coefficients, while the deployed actor relies strictly on onboard joint encoders, IMU angular velocity, and action history.
- **Actuator Network & Latency Modeling**: Models series-elastic torque lag and 20 ms control-loop jitter directly inside vectorized rollouts.
- **Adaptive Terrain Curriculum**: Automatically promotes policies from flat planes to slopes, stairs, and randomized rubble grids once linear velocity tracking error drops below threshold.

import torch.nn as nn

class AsymmetricActorCritic(nn.Module):
    def __init__(self, obs_dim: int, priv_dim: int, act_dim: int):
        super().__init__()
        self.actor = nn.Sequential(
            nn.Linear(obs_dim, 256), nn.ELU(),
            nn.Linear(256, 128), nn.ELU(),
            nn.Linear(128, act_dim),
        )
        self.critic = nn.Sequential(
            nn.Linear(obs_dim + priv_dim, 512), nn.ELU(),
            nn.Linear(512, 256), nn.ELU(),
            nn.Linear(256, 1),
        )
        self.log_std = nn.Parameter(torch.zeros(act_dim))`
