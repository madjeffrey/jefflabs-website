## Why We Replaced Monolithic UI Kits with Modular Tailwind Primitives

When building sports analytics tools and personal engineering portfolios, heavy third-party component frameworks often lock you into rigid styling tokens and bloated runtime bundles. By refactoring to **Next.js App Router + strict TypeScript + Tailwind CSS**, every component in `src/components/ui/` is transparent, composable, and easy to extend.

## Clean Separation of Config, Content, and UI

1. **Configuration (`src/resources/site.config.ts`)**: Controls enabled routes, password-protected scouting pages, typography, and background court spotlight effects.
2. **Typed Content (`src/resources/content.tsx`)**: Holds personal profile metadata, volleyball telemetry metrics, work experience, and gallery items with full TypeScript autocomplete.
3. **Composable Primitives (`src/components/ui/`)**: Self-contained `Button`, `Badge`, `Carousel`, `Media` (with full-screen Lightbox), `CodeBlock`, and `HeadingNav` components styled with Tailwind CSS variables.
